## `./featured-projects`

### 🚀 Interceptor UAV Prototype

**Custom 3D-printed interceptor-style UAV**

A proof-of-concept UAV developed with **Jay Biswas**, taking the project from CAD and fabrication through system integration and flight testing.

**Hardware / systems**
- Custom 3D-printed airframe
- Goku H743 flight-controller stack
- ELRS control link
- GPS telemetry
- 6S power system
- Iterative aerodynamic and weight-distribution optimization

**Test result:** `118 km/h` GPS-recorded maximum speed.

The project evolved through multiple airframe iterations, focusing on geometry, battery placement, stability, responsiveness and flight characteristics. Future exploration includes autonomous operation, target tracking and swarm-oriented UAV concepts.

### 🛩️ RC Aircraft Design & Flight System

**Cognizance — IIT Roorkee | Flight Fury**

Designed and built a fixed-wing RC aircraft for competition, working across airframe assembly, basic aerodynamics, control-system setup and flight testing.

### 🤖 Autonomous Drone System

Developed an autonomous drone system with a **custom monitoring dashboard** for real-time data visualization and control.

Worked on sensor integration, flight-data monitoring, dashboard development and UAV system behaviour.

### 📡 IoT Distance Sensing & Object Detection Alarm

An embedded/IoT project using an **Arduino UNO WiFi R3**, ultrasonic sensing and Wi-Fi connectivity.

